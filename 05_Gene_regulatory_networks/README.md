# 05 — Gene regulatory networks (SCENIC+)

**Paper Methods:** GRN inference (preprocessing → topic modelling → eGRN inference).

**Cluster only.** Do not run either step on a laptop.

## Two steps, two kinds of files

**1. Preprocessing (Jupyter, cluster)**  
`SCENICPLUS_preprocessing_Patient1_03H096.ipynb`  
Builds consensus peaks, the cisTopic object, Mallet topics and `outs/region_sets/`.

**2. eGRN inference (Snakemake, cluster — not a notebook)**  
`config.yaml`  
This is the official SCENIC+ Snakemake config that was submitted after preprocessing. In this workflow, eRegulon inference is performed through Snakemake rather than in Jupyter. You initialise the Snakemake workflow from the `scenicplus` package, replace its default config with this file, and run `snakemake --cores 20`.

```text
scenicplus init_snakemake --out_dir scplus_pipeline
cp config.yaml scplus_pipeline/Snakemake/config/config.yaml
cd scplus_pipeline/Snakemake && snakemake --cores 20
```

That job used 20 CPUs and HTCondor node scratch (`temp_dir` in the YAML). In `config.yaml`, set `PATH_TO_PROJECT` and `PATH_TO_MOTIF_DB` to your cluster paths; leave the parameters.

`SCENICPLUS_snakemake_Patient1_03H096.ipynb` only documents those commands and reprints the full YAML. The Snakefile is generated by `scenicplus`; it is not stored in Git.

## What Snakemake writes

- `outs/scplusmdata.h5mu` (main SCENIC+ MuData)
- eRegulon tables, AUCell matrices, motif-enrichment HDF5 files (see `output_data` in `config.yaml`)

## Inputs

- Cleaned MultiVI object with final cluster labels (folders `01` / `02`) — for preprocessing
- hg38 cisTarget motif databases (not in Git) — for Snakemake
